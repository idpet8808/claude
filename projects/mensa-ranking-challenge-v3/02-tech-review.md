### 컴포넌트 구성

```
[멘사코리아 기존 사이트 (PHP)]
       |
       ├── [온라인테스트 첫 페이지] ── (JS 랭킹 위젯 삽입 — PHP API 호출)
       |                                      ↓
       └── [챌린지 레이어 (신규 — mensa.kr/challenge)]
              |
              ├── [Frontend (Vanilla JS + PHP 템플릿)]
              |        ↓
              ├── [Backend PHP API 엔드포인트] ── [RDB (MySQL 또는 PostgreSQL)]
              |        ↓
              ├── [이니시스 PG] (결제창 팝업/인라인)
              |        ↓
              └── [정적 파일 서버] (문제 PNG + SVG 컴포넌트)
```

### 주요 데이터 흐름

1. 로그인 회원 → PHP 세션 확인 → 챌린지 진입 → 5문제 순차 풀이 (문제 시작 타임스탬프 PHP 서버 기록) → 제출 → 채점 → 랭킹 갱신 → 결과 화면
2. 힌트/패스 요청 → 아이템 보유량 확인 → 미보유 시 이니시스 결제창 → 콜백 수신 → 아이템 지급 → 감점 반영
3. 탭 이탈 감지(Visibility API) → JS 이벤트 → PHP API 기록 → 관리자 대시보드 표시
