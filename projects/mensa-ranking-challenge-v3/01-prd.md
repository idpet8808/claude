# PM 비즈니스 배경 (멘사 랭킹 챌린지 v3)

- 작성일: 2026-05-08 (재작성 — v2-0은 2026-05-07 비교군 보존)
- 대상: 멘사 로그인 회원
- 형태: 멘사 오리지널 문제 기반 온라인 랭킹 챌린지
- MVP 문제 수: 5개

## 1. 서비스 개요

멘사 로그인 회원이 멘사 오리지널 문제 5개로 구성된 챌린지에 무료로 도전하고, 결과에 따라 랭킹에 등록되는 서비스다.

온라인테스트 첫 페이지에 랭킹을 노출해 회원의 도전 욕구를 자극하고, 풀이 중 막히는 지점에서는 힌트와 패스 아이템을 유료로 사용할 수 있게 한다. 관리자는 챌린지 참여 현황, 문제별 정답률, 아이템 사용량, 결제 현황, 랭킹 현황을 확인한다.

## 2. 핵심 콘셉트

"멘사 정회원 전용 퍼즐 챌린지"

미스터에그 대탐험처럼 짧은 스테이지를 하나씩 통과하는 구조를 모티브로 삼되, 캐릭터나 화면 구성은 직접 차용하지 않는다. 멘사 브랜드에 맞게 가볍고 귀여운 게임보다 정교한 두뇌 챌린지 경험으로 설계한다.

- 문제 5개 = 스테이지 5개
- 각 문제를 풀면 다음 단계로 진행
- 전체 점수와 풀이 시간으로 랭킹 산정
- 힌트 = 단계별 단서
- 패스 = 해당 문제를 넘기는 아이템
- 유료 패스권 = 힌트/패스 묶음 상품

## 3. 대상 사용자

- 기존 멘사 로그인 회원
- 비로그인 사용자는 챌린지 참여 불가
- 별도 회원가입 또는 비회원 체험은 MVP 범위에서 제외
- 랭킹, 도전 기록, 결제 내역은 로그인 회원 계정 기준으로 저장

## 4. MVP 핵심 기능

1. 온라인테스트 첫 페이지 랭킹 노출
2. 로그인 회원 전용 챌린지 진입
3. 5문제 연속 풀이
4. 점수와 시간 기반 랭킹 산정
5. 문제당 3단계 힌트 제공
6. 힌트 아이템 유료 구매 및 사용
7. 패스 아이템 유료 구매 및 사용
8. 유료 패스권 상품 판매
9. 관리자 현황 대시보드

## 5. 현재 문제 구성

| 문제명 | 유형 | 기획 평가 |
|---|---|---|
| 배수 수열 | 숫자 배치형 수열 문제 | 온라인화에 적합, 변형 가능성 높음 |
| 11배수 스도쿠 | 9x9 그리드 입력형 | 조작형 UI에 적합, 랭킹 챌린지와 잘 맞음 |
| 너는 바보입니다 | 문자/숫자 대응 암호형 | 재미는 있으나 AI 캡처 풀이에 다소 취약 |
| 아 치킨먹고싶다 | 자기참조형 논리 문제 | 변별력은 좋지만 텍스트 기반이라 AI 취약성 높음 |
| 아름다운 수열 | 32칸 고리형 배치 퍼즐 | 구현 난이도는 높지만 대표 스테이지로 적합 |

## 6. 챌린지 진행 방식

- 총 5문제를 연속으로 풀이
- 문제는 순차 진행을 기본으로 한다
- 각 문제에서 힌트 또는 패스를 사용할 수 있다
- 모든 문제 완료 후 결과 화면에서 점수, 시간, 아이템 사용 내역, 랭킹을 표시한다
- 재도전은 가능하되 최고 기록과 모든 도전 이력을 저장한다

## 7. 힌트 정책

문제당 힌트는 3단계로 제공한다.

| 단계 | 역할 |
|---|---|
| 힌트 1 | 관찰 방향 제시 |
| 힌트 2 | 핵심 규칙 암시 |
| 힌트 3 | 풀이 접근법 제공 |

원칙:
- 힌트는 순서대로만 열 수 있다
- 한 번 연 힌트는 다시 볼 수 있다
- 힌트 3도 정답값을 직접 제공하지 않는다
- 힌트 사용 내역은 점수와 랭킹에 반영한다

## 8. 점수 및 랭킹 정책

시간만으로 랭킹을 정하지 않고, 점수와 시간을 함께 사용한다.

기본안:
- 문제 점수: 최대 100점
- 시간 보너스: 최대 20점
- 랭킹 점수: 문제 점수 + 시간 보너스 - 아이템 감점
- 총 랭킹 기준 점수: 120점

예시:
- 힌트 1 사용: -2점
- 힌트 2 사용: 추가 -3점
- 힌트 3 사용: 추가 -5점
- 패스 사용: 해당 문제 0점
- 동점 시 풀이 시간이 짧은 회원 우선
- 그래도 동점이면 먼저 제출한 회원 우선

## 9. 랭킹 구분

공정성을 위해 랭킹은 분리한다.

| 랭킹 | 기준 |
|---|---|
| 공식 랭킹 | 힌트/패스 미사용 또는 이상 패턴 없는 기록 중심 |
| 완주 랭킹 | 힌트/패스 사용 기록 포함 |
| 개인 기록 | 본인의 최고 점수와 도전 이력 저장 |

## 10. AI 취약성 대응 방향

AI 사용을 완전히 차단하는 것은 현실적으로 어렵다. 따라서 목표는 "AI 차단"이 아니라 "공식 랭킹 신뢰도 보호"로 잡는다.

MVP부터 고려할 항목:
- 제한 시간 적용
- 문제를 단순 텍스트형보다 조작형 UI로 구현
- 힌트/패스 사용 기록 저장
- 공식 랭킹과 완주 랭킹 분리
- 비정상적으로 빠른 제출 기록 관리자 표시
- 탭 이탈 또는 재진입 기록 저장

후속 검토 항목:
- 회원별 문제 변형 seed
- 숫자/위치/보기 순서 랜덤화
- 문제별 AI 취약도 분석
- 공식 랭킹 보류/검수 기능

## 11. 관리자 기능

관리자는 다음 현황을 확인할 수 있어야 한다.

- 랭킹 Top 회원

- 비정상 풀이 의심 기록

## §A 비전 (PM 원본 기반 정형화)

> §A는 §0 PM 원본을 *바탕으로 정형화*. service-planner 작성 영역. KPI(성공 지표) 제거 — PRD 본질(요구사항 정의서)과 무관.

### A-1. WHY — 왜 이걸 만드는가

멘사코리아는 기존 사이트에 온라인테스트 기능을 운영 중이다. 그러나 회원들이 자발적으로 재방문하거나 서로 경쟁할 수 있는 참여형 콘텐츠가 부재하다. 멘사 오리지널 문제를 활용한 퍼즐 챌린지 서비스를 신설하여, 회원의 도전 욕구를 자극하고 랭킹 경쟁을 통해 플랫폼 체류 및 재방문을 유도한다.

풀이 중 막히는 지점에서 힌트·패스 아이템을 유료로 제공함으로써 수익 모델도 겸한다. 기존 비즈니스 구조(멘사코리아 사이트 + 로그인 회원 기반)를 그대로 활용하되, 챌린지와 랭킹이라는 새로운 참여 레이어를 추가하는 방식이다.

관리자는 참여 현황·정답률·아이템 사용량·결제·랭킹을 한 화면에서 파악할 수 있어야 한다. 이를 통해 문제 난이도 조정, 아이템 정책 변경, 이상 풀이 관리 등 운영 의사결정의 근거를 확보한다.

### A-2. 1차 사용자

**주 사용자**: 멘사코리아 기존 로그인 회원 — 20~40대, 두뇌 퍼즐에 관심이 높으며 온라인테스트 경험이 있는 회원

**부 사용자**: 멘사코리아 관리자 — 챌린지 운영·결제·이상 기록 관리 담당

**사용자 맥락**: 주 사용자는 멘사코리아 사이트에 로그인한 상태에서 온라인테스트 첫 페이지의 랭킹 노출을 보고 챌린지에 진입한다. 5문제를 순차적으로 풀며 자신의 점수와 시간을 랭킹과 비교한다. 막히는 문제에서 힌트 구매를 고려하고, 재도전을 통해 기록을 개선하려 한다.
