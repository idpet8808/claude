## 1. WHY — 왜 이걸 만드는가

멘사는 IQ 상위 2% 이상을 인증하는 국제 단체로, 국내 사이트에서 온라인 IQ 테스트와 퀴즈 콘텐츠를 제공하고 있다. 그러나 현재 구조에서는 **회원 간 경쟁 또는 비교 수단이 전혀 없어** 콘텐츠 소비 후 재방문할 동기가 부족하다. 방문자는 IQ 테스트 한 번 이용 후 이탈하는 패턴이 반복되며, 회원 활성화 지표가 낮은 상태다.

멘사는 자체 보유한 다수의 오리지널 문제·퀴즈 자산을 보유하고 있다. 이 자산을 **랭킹 경쟁 구조**와 결합하면 "재도전 — 성취 — 비교"의 동기 루프를 만들 수 있다. 챌린지 도전 자체는 무료로 개방하여 진입 장벽을 낮추고, 힌트·패스 아이템 및 유료결제 패스를 부가 상품으로 판매하는 구조로 수익화한다.

구체적으로: **온라인테스트 첫 페이지에 랭킹을 노출**함으로써 기존 유입 경로(IQ 테스트 방문자)를 그대로 활용하여 챌린지 참여로 자연 전환을 유도한다. 이를 통해 재방문율 제고, 유료 아이템 결제 전환, 멘사 오리지널 콘텐츠의 상품 가치 실현이라는 세 가지 비즈니스 목표를 동시에 달성한다.

관리자 페이지를 통해 챌린지 운영·결제·랭킹 현황을 모니터링하여 운영 효율을 확보한다.

## 2. 1차 사용자

**주 사용자**: 30~40대 멘사 정회원 또는 일반 사이트 가입자, 도전 성취형, 월 1~2회 온라인테스트 페이지 방문자 [서비스기획자 추정 — PM 확정 대기, 오픈 이슈 #1]

**부 사용자**: 멘사 운영 담당자 (관리자 페이지를 통해 챌린지·결제·랭킹 현황 모니터링)

**사용자 맥락**: 주 사용자는 온라인테스트 첫 페이지에 접속했다가 랭킹 노출을 보고 호기심이 생겨 챌린지에 도전한다. 성취 욕구가 높아 현재 자신의 순위를 확인하고, 상위권 진입을 위해 재도전하거나 힌트를 구매하는 행동 패턴을 보인다.

## 4. 기능 범위 (MoSCoW)

### Must (5개 이하)

1. **랭킹 시스템** — 챌린지 결과를 기반으로 회원별 점수 집계 및 순위 표시 (온라인테스트 첫 페이지 노출 포함)
2. **챌린지 도전 (무료)** — 멘사 오리지널 문제·퀴즈를 이용한 챌린지 참여, 로그인 회원 대상 무료 개방
3. **힌트·패스 아이템 유료 판매** — 챌린지 진행 중 힌트 제공 또는 문항 패스 기능, 개별 유료 구매
4. **유료결제 패스 상품** — 힌트·패스 아이템을 묶음 구매하는 구독/패스 상품
5. **기존 멘사 회원 DB 연동** — 기존 회원 인증·세션을 활용하여 신규 가입 불필요, 챌린지 참여 이력 저장

### Should

- 관리자 페이지 — 챌린지 현황·결제 통계·랭킹 현황 모니터링 대시보드 [Must 격상 가능 — 오픈 이슈 #3]
- 챌린지 카테고리 분류 — 문제 유형별(논리·수리·언어 등) 챌린지 분류 및 개별 랭킹
- 챌린지 이력 조회 — 회원 마이페이지에서 참여 이력 및 점수 변화 확인

### Could

- 챌린지 시즌제 — 월간/분기별 리셋으로 신규 참여 동기 부여
- 뱃지·칭호 시스템 — 특정 조건 달성 시 프로필 뱃지 부여
- 상위권 회원 명예의 전당 — 역대 최고 기록 영구 보관

### Won't (제외 범위 명시)

- 외부 SNS(카카오·네이버·페이스북 등) 연동 랭킹 공유 기능 [서비스기획자 추정 — PM 확정 대기, 오픈 이슈 #4]
- 글로벌 멘사 지부 간 통합 랭킹
- 실시간 1:1 대전 기능
- 모바일 네이티브 앱 별도 출시 (웹 반응형 범위 내 처리)

## 5. 주요 사용자 시나리오

### 시나리오 1: 정상 경로 — 챌린지 참여 및 랭킹 확인

1. 회원이 온라인테스트 첫 페이지에 접속한다.
2. 상단에 노출된 랭킹 현황(1~5위 미리보기)을 확인하고 "나도 도전" 버튼을 클릭한다.
3. 로그인 상태 확인 후 챌린지 목록 페이지로 이동한다.
4. 원하는 챌린지를 선택하고 문제 풀이를 시작한다 (무료).
5. 풀이 도중 어려운 문항에서 힌트 구매를 결정, 결제 모달에서 유료 힌트를 구매한다.
6. 챌린지를 완료하면 점수와 현재 랭킹 순위가 즉시 표시된다.
7. 랭킹이 실시간 반영되며, 온라인테스트 첫 페이지 랭킹에도 자신의 순위가 노출된다.

### 시나리오 2: 실패/예외 경로 — 비회원 접근 및 결제 실패

**2-A. 비회원 접근**

1. 비로그인 방문자가 온라인테스트 첫 페이지의 랭킹을 보고 "도전하기"를 클릭한다.
2. 시스템이 로그인 상태가 아님을 감지하여 로그인/회원가입 페이지로 리디렉션한다.
3. 기존 멘사 회원 계정으로 로그인 후 챌린지 페이지로 자동 복귀한다.
4. 비회원인 경우 회원가입 안내 메시지를 표시한다.

**2-B. 유료 아이템 결제 실패**

1. 회원이 챌린지 진행 중 힌트 구매 버튼을 누른다.
2. 결제 모달이 열리고 카드 정보를 입력한다.
3. 결제 처리 중 오류(카드 한도 초과, 네트워크 오류 등)가 발생한다.
4. 시스템이 결제 실패 메시지와 원인을 표시하고, 힌트는 지급하지 않는다.
5. 회원은 다른 결제 수단을 선택하거나 힌트 없이 계속 진행할 수 있다.
6. 챌린지 진행 상태(현재 문항, 경과 시간)는 결제 실패와 무관하게 유지된다.
