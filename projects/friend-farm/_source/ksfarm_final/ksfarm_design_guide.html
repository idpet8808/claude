KS팜 디자인 가이드

'AI 농사친구' 앱 디자인 시스템. 45개 화면 분석에서 실제로 거의 모든 화면이 같은 값을 쓰는 것만 표준으로, 화면마다 의도가 있는 항목은 변형 예시로 정리했어요. 토스급 미니멀 + 어스톤 따뜻함 톤.
미니멀 + 어스톤 모바일 ~390px 한국어 농업 앱 v3 · 2026-05-29

이 가이드의 사용 원칙

1. 토큰과 공통 컴포넌트는 그대로 따른다. 컬러·타이포·기본 컨테이너는 모든 화면에서 동일하게.
2. 레이아웃·여백·세부 사이즈는 화면 의도에 맞춰 자유롭게. 화면마다 정보 위계가 달라서 통일하면 안 된다.
3. 이미 잘 맞춰진 화면을 사후 일괄 통일하지 않는다. 새 화면 만들 때만 이 가이드 참고.

13특수 규칙

KS팜 특유의 도메인 규칙.
시세 등락 색 — 농민 관점 반전
앱 전체 규칙
일반 주식 앱은 상승 = 빨강, 하락 = 파랑이지만, 농민 관점에선 가격 상승 = 어스 톤 강조(테라코타), 가격 하락 = 차분한 그린(농민에게 우호적이지 않음을 의도적으로 차분히 표현).
오이

딸기
18,900원 ↘ 2.1%

border-top 구분선 + 헤더 + 본문 패턴으로 가독성 확보.
✓

❌ 회피 패턴
✗
인라인 hex 컬러 (그라데이션 stop 외)
토큰 변수로 통일. 그래야 일관성 유지·수정 용이.
✗
본문에 진하지 않은 회색 (#999 등)
가독성·접근성 문제. --ink-2/--gray 사용.
✗
아이콘 폰트 사이즈로 크기 조절
SVG는 font-size 안 먹음. width/height로 명시.
✗
그림자 진하게
0 1px 2px rgba(36,30,18,.05) 미니멀하게.
✗
이미 잘 맞춰진 화면을 사후 일괄 통일 ← 이번 세션 교훈
