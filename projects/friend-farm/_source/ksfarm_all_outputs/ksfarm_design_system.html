v3 · 45개 화면 표준화 기반 · 마지막 업데이트 2026-05-29
hybrid 톤 미니멀 + 어스톤 모바일 ~390px 한국어 농업 앱

0. 컨셉

미니멀(토스급 명료함) 구조 + 어스톤(KS팜다운 따뜻함) 팔레트
철학

정보는 명료하게, 색·질감은 농업/자연 정서에 맞게 따뜻하게. 장식은 의미가 있을 때만. 토스의 명료함을 따르되, 한국 농업인이 보는 화면이라는 정서를 잃지 않는다.

원칙
  • 주인공 하나에 집중 (나열하지 말 것)
  • 비율·위계·호흡으로 채움
  • 위계: 새 정보가 주인공, 아는 정보는 작게
  • 자동 진행보다 명시적 다음 버튼
  • 카드 4개 이상 연달면 텍스트 흐름으로

증상 설명

잎 표면에 밀가루를 뿌린 듯한 흰색 분생포자가 덮이며, 진전되면 잎이 누렇게 변하고 말라 떨어집니다.

기온 20~25°C의 서늘하고 건조한 조건에서 잘 발생합니다.

16. 사용 금지 / 회피 패턴

자주 실수하는 패턴 모음. v3 위반 사례.
  • ❌ 카드 4개 이상 연속 — 가독성 떨어짐. .sec 텍스트 흐름으로 전환 (border-top 구분선 + 헤더 + 본문)
  • ❌ 아이콘 폰트 사이즈로 크기 조절 — SVG는 width/height 직접 지정
  • ❌ 그림자 진하게 — var(--shadow) 미니멀하게
  • ❌ #999 같은 인라인 회색 본문 — 토큰 변수 사용 (--ink/--ink-2/--gray)
  • ❌ 인라인 hex 컬러 — 토큰 변수 사용 (그라데이션 stop만 예외)
  • ❌ 자동 다음 진행 — 명시적 "다음" 버튼 통일 (실수 방지)
  • ❌ 답카드 두껍게 — .ans 표준 패턴 유지 (둔해 보임)
  • ❌ 이모지 작물 라벨 — 텍스트만 사용 (톤 일관성)
