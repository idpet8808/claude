## 1. 컬러 팔레트 (CSS 토큰)

```css

  --ink:       #20251D;   /* 본문 진한 텍스트 */
  --ink-2:     #45493E;   /* 보조 텍스트 */
  --gray:      #76796C;   /* 캡션/뮤트 */
  --line:      rgba(48,42,30,.10);  /* 구분선/테두리 */

  /* 메인 (딥 틸-포레스트) */
  --green:     #1F4B3C;   /* 주 브랜드/CTA */
  --green-2:   #163729;   /* CTA 그라데이션 하단 */
  --green-soft:#E7EEE6;

  /* 경고 신호 — 진짜 경고에만 (따뜻한 테라코타) */
  --red:       #B0612C;
  --red-soft:  #F3E6D6;

  /* 어스 멀티 액센트 — 아이콘 타일 의미 부여용 */
  --gold:      #B08A3E;  --gold-soft: #F2E9D2;  /* 지원사업/혜택 */
  --clay:      #B0612C;  --clay-soft: #F3E1D2;  /* 병해충/주의 */
  --sage:      #2F6150;  --sage-soft: #E4ECE0;  /* 재배/생장 */

  /* 시세 등락 (농업인=판매자 관점) */
  /* 상승 = 호재(긍정 그린) #2A7A52 / 하락 = 차분한 클레이 var(--clay) */

  /* 모서리 */
  --r-lg: 18px;  --r-md: 14px;  --r-sm: 10px;

  /* 그림자 (절제) */
  --shadow: 0 1px 2px rgba(36,30,18,.05);
}
```

### 색 사용 원칙
- **색은 의미가 있을 때만.** 장식 목적의 색 채움 금지.
- **경고색(클레이/테라코타)** 은 D-day 마감, 병해 위험 등 "진짜 주의"에만. 한 화면에 경고 신호 1개 원칙.
- **멀티 액센트(골드/클레이/세이지)** 는 카테고리 아이콘 타일에 의미 부여용으로만 사용.
- **시세 등락**: 상승=긍정 그린(`#2A7A52`), 하락=클레이. (판매자에겐 가격 상승이 호재)

## 4. 핵심 컴포넌트 규칙

### 4-1. 상단바 (톱바)
- 좌: **햄버거(☰)** + **위치 버튼**(📍 강남구 역삼동 ▾, ink색·15px·700)
- 우: **알림(🔔)** 하나만 (빨간 점 = 미확인). 채팅 아이콘 없음.
- 아이콘은 **칩 배경 없는 플레인** 아이콘(24px). 양끝은 콘텐츠 마진에 맞춰 정렬(-8px).
- 로고/앱명 표시 안 함(이미 앱 내부이므로).

### 4-2. 히어로
- 카드 없이 굵은 타입으로 (hybrid/minimal) — 단, apple 변형은 카드형.
- **컨셉 (확정 v2 — "진단 행동 직결 + AI 농사친구 톤"):** 병해 위험 '등급'을 단정해 보여주지 않는다. (NCPMS 예측 데이터는 지도위젯 중심·작목/지점 의존이라 "병해 위험 높음" 같은 실시간 단정이 불안정 → 회피.) 대신 히어로는 "물어보면 답해주는 친구"라는 정체성을 담아, 사진으로 묻는 행동(=병해진단 CTA)으로 자연스럽게 유도한다.
- 구성(3단 카피 구조): 인사말(eyebrow) → 헤드라인(공감·말걸기) → 본문(가치 한 줄) → 날씨 한 줄 → 메인 CTA.
  - 셋의 역할 분담(같은 말 반복 금지): 헤드라인=공감, 본문=권유, CTA=행동.
  - 확정 카피: 헤드라인 "오늘 작물은 / 잘 지내고 있나요?", 본문 "궁금한 건 언제든 농사친구에게 물어보세요.", CTA "사진으로 물어보기 / 사진 한 장이면 작물 상태를 살펴봐 드려요".
- **날씨 = 한 줄, 알약(pill) UI:** `23.1° · 습도 82% · 강수 60%` (기온·습도·강수만, 기상 API 기반). **병해 위험 라벨 없음.** 흰 배경 + 1px `--line` 테두리 + `--shadow`의 통짜 알약 하나(C안)로 감싼다 (apple은 기존 흰 박스형 weather-row가 동일 역할). 아이콘 형태로 날씨 표현 금지, 텍스트로.
  - 데이터 의존: 기상 API(기온·습도·강수)만. 농장 정보/병해 위험 등급에 의존하지 않음 → 데이터가 비어도 안 깨짐.
- **메인 CTA(사진 병해진단)**: 딥틸 그라데이션 `linear-gradient(180deg,#2C6150,#1F4B3C 52%,#163729)` + 상단 림 하이라이트 + 2단 그림자. 좌측 반투명 아이콘 타일. 화면 단일 포컬. 문구는 친구 톤("사진으로 물어보기")으로, 딱딱한 기능명("병해 진단") 지양.
- *보류 항목: 날씨 조건별 '조건부 주의 톤' 본문(2안)은 설계 추가 검토 후 반영. 시기성 병해 정보 카드(3안)는 발생조건 자연어 파싱 리스크로 보류.*

### 4-3. 아이콘 타일 (입체 "절제된 클레이")
모든 아이콘 타일/원형 토큰에 공통 적용하는 입체 레시피(과하지 않게):
```css
box-shadow:
  inset 0 1px 0 rgba(255,255,255,.7),   /* 상단 림 하이라이트 */
  0 2px 5px -1px rgba(46,34,20,.14);     /* 옅게 떠 있는 그림자 */
background: linear-gradient(160deg, [밝은톤] 0%, [소프트톤] 100%);
```
- 카테고리 타일 색: 지원사업=골드, 병해충=클레이, 재배=세이지 (톤온톤, 옅게)
- 클레이 풀입체(apple 버전)는 더 강한 그림자를 쓰지만, **기본은 절제 버전**.

### 4-4. 리스트 카드 (트랜잭션 스타일)
- 흰 카드(`--card`) + `--line` 테두리 + `--shadow`, radius `--r-lg`.
- 행(row): `[원형/라운드 토큰 38px] [제목+부제] ───── [우측 값/액션]`
- 행 사이 구분: `border-top: 1px solid var(--line)` (첫 행 제외).
- **앵커(`<a>`)를 카드/행으로 쓸 땐 반드시 `display:block` / 행은 `width:100%`** (인라인 렌더 깨짐 방지 — 실제로 겪은 버그).

### 4-5. 섹션 헤더
- 단일 목적지가 분명할 때만 우측에 "더보기/전체보기". (예: 시세=O)
- 항목 수가 적어 이미 다 보이면 액션 링크 두지 않음(예: "확인할 일 2건"엔 없음).
- 리스트 끝에 "전체 N 보기" 행을 카드 안 푸터로 두는 패턴 사용 가능
  (`.more-row` / `.price-more`: 중앙정렬, 상단 border-top, gray, 우측 chevron).
- 부제(날짜 등)가 있으면: 제목 옆 우측 끝에 작게(`align-self: baseline`) — A안 확정.
  *(대안: 제목 아래 2줄 스택. eBay 패턴. 둘 다 허용.)*

## 7. 버전 메모
- **hybrid = 메인 채택안.** (미니멀 구조 + 어스톤 팔레트) — **현재 hybrid가 최신 확정본(v2).**
- minimal(그린 단색)·apple(클레이 풀입체 어스톤)은 비교용 변형. 필요시 참고만. *(v2 변경 일부 반영됨: 4안 카피·키워드 칩·답변 라벨 제거·날씨. 단 히어로 v2 리듬/시세 2개는 hybrid에만 반영 — 동기화는 추후 결정.)*
- **시세 위젯 구조 통일**: "오늘의 작물 시세" 제목 + 작물명 옆 ★(관심 표시) + **최대 2개** + "전체 시세 보기" 푸터. ★ 색만 팔레트에 맞춤(hybrid·apple=골드, minimal=그린).
- 시세 위젯의 "AI 시세 요약" 한 줄은 홈에서 제외함(기획상 차별점이라, 추후 *시세 상세 화면* 안에 배치 검토).
- 시세 작물 토큰(🥒🍓 등 컬러 이모지)은 화면의 단색 라인 톤과 불일치 + 기기별 모양 차이 + 품목 多(50~100종) 확장성 이슈로 **미해결 보류**. (자체 일러스트 부담 큼 → 단색 실루엣 세트 / 오픈소스 농산물 아이콘 세트 / 토큰 제거 숫자중심 중 추후 결정.)

### 7-1. v2 변경 이력 (메인 홈 고도화 세션)
- 히어로: "병해 위험 등급" 단정 제거 → **진단 행동 직결(4안) + AI 농사친구 톤** 카피로 전환.
- 히어로 리듬: 균등 간격 → **위 여백 크게(68px) + 콘텐츠 블록 타이트 묶음**.
- 날씨: 맨 텍스트 → **통짜 알약(C안)**, 습도 추가, 병해 라벨 제거.
- 시세: 최대 3개 → **2개**.
- 맞춤 정보 피드: 기능 묶임 라벨 제거 → **키워드 칩**.
- 전문가 답변: "전문가 답변 요약:" 라벨 제거 → 본문만.
- 부수효과: 히어로 클레이 경고 제거로 화면 경고색이 피드 D-3 하나로 정리(§"경고 신호 1개" 부합).
- 데이터 연동 메모: 병해 위험은 NCPMS Open API(`ncpms.rda.go.kr/npmsAPI/service`, serviceCode 방식; 예측=SVC31 지도위젯, 검색=SVC01~03)로 가능하나 실시간 위험등급 직접 추출이 불안정 → 현 단계 히어로는 기상 데이터만 사용.
