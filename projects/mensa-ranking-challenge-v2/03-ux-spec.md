## 2. 화면 명세 (화면별)

### S-001 (→ REQ-001, REQ-003)

**화면명**: 메인(홈)

**사용자 목표**: 서비스를 처음 접한 사용자가 챌린지의 개념을 빠르게 파악하고 "시작하기"를 누른다.

**진입 경로**:
- SNS 공유 링크 직접 접근 (`/`)
- 브라우저 즐겨찾기 또는 직접 URL 입력
- 랭킹·결제 화면에서 로고 클릭

**영역 구성**:

| 영역 | 역할 | 포함 컴포넌트 |
|------|------|--------------|
| 글로벌 헤더 | 로고, 네비게이션, 로그인/회원가입 버튼 | NavBar |
| 히어로 | 서비스 한 줄 소개 + "챌린지 시작" 메인 CTA | HeroSection |
| 챌린지 미리보기 | 5종 챌린지 카드 썸네일 나열 | ChallengeCardList |
| 랭킹 프리뷰 | 통합 랭킹 상위 5명 + "전체 랭킹 보기" 링크 | RankingPreview |
| IQ 응시권 배너 | 결제 전환 유도 고정 배너 | ConversionBanner |
| 글로벌 푸터 | 개인정보처리방침, 이용약관 | Footer |

**4가지 상태** (모두 필수):

#### 정상 상태
히어로 텍스트와 CTA 버튼 표시. 챌린지 카드 5종 모두 노출. 랭킹 프리뷰에 상위 5명 데이터 표시. 비회원 상태에서도 전체 화면 열람 가능.

#### 빈 상태 (Empty)
랭킹 프리뷰 데이터 없음(서비스 초기): "아직 랭킹이 없습니다. 첫 번째 도전자가 되세요!" 문구 + "챌린지 시작" CTA 노출. 챌린지 카드는 항상 5종 고정이므로 빈 상태 없음.

#### 에러 상태 (Error)
랭킹 API 실패 시: 랭킹 프리뷰 영역에만 "랭킹을 불러오지 못했습니다. [새로고침]" 인라인 에러 표시. 히어로·챌린지 카드는 정적 콘텐츠이므로 영향 없음.

#### 로딩 상태 (Loading)
페이지 최초 진입 시 랭킹 프리뷰 영역에 스켈레톤 3행 표시 (히어로·챌린지 카드는 정적이므로 즉시 렌더).

**인터랙션**:

| 트리거 | 동작 | 결과 상태 |
|--------|------|----------|
| "챌린지 시작" CTA 클릭 | S-002(챌린지 선택)로 이동 | S-002 정상 상태 |
| 챌린지 카드 클릭 | 해당 챌린지 S-003으로 직접 이동 | S-003 정상 상태 |
| "전체 랭킹 보기" 클릭 | S-005(랭킹 조회)로 이동 | S-005 정상 상태 |
| IQ 응시권 배너 클릭 | 로그인 여부 분기: 비회원→S-007(로그인), 회원→S-008(결제) | S-007 또는 S-008 |
| 로그인 버튼 클릭 | S-007(로그인)로 이동 | S-007 정상 상태 |

**기술 제약 반영**:
- 02-tech-review.md broadcast 수신 전 — PG 연동·랭킹 캐시 정책 등 기술 제약은 수신 후 보완.

### S-002 (→ REQ-001)

**화면명**: 챌린지 선택

**사용자 목표**: 5종 챌린지 중 원하는 것을 선택하고 시작한다.

**진입 경로**:
- S-001 "챌린지 시작" CTA 클릭
- 글로벌 네비게이션 "챌린지" 메뉴

**영역 구성**:

| 영역 | 역할 | 포함 컴포넌트 |
|------|------|--------------|
| 글로벌 헤더 | 로고, 네비게이션 | NavBar |
| 챌린지 그리드 | 5종 카드 (이름·유형·예상 소요 시간·난이도) | ChallengeGrid |
| 참여 이력 배지 | 이미 완료한 챌린지에 "완료" 배지 오버레이 (회원만) | CompletionBadge |

**4가지 상태** (모두 필수):

#### 정상 상태
5종 챌린지 카드 모두 노출. 회원은 완료 배지 표시. 비회원은 배지 없이 전체 선택 가능.

#### 빈 상태 (Empty)
챌린지 목록은 서버 고정값(5종)이므로 빈 상태 해당 없음. 단, 이 상태를 명시적으로 처리: 데이터 로드 실패 시 에러 상태로 전환.

#### 에러 상태 (Error)
챌린지 목록 API 실패: "챌린지 목록을 불러오지 못했습니다. [다시 시도]" 전체 영역 에러 메시지. 재시도 버튼으로 API 재호출.

#### 로딩 상태 (Loading)
챌린지 카드 5개 자리에 스켈레톤 카드 5개 표시.

**인터랙션**:

| 트리거 | 동작 | 결과 상태 |
|--------|------|----------|
| 챌린지 카드 클릭 | 해당 챌린지 S-003으로 이동 | S-003 정상 상태 |
| 완료된 챌린지 카드 클릭 (회원) | S-003 진입 (재도전 허용 — REQ-009 Could) | S-003 정상 상태 |

### S-003 (→ REQ-001, REQ-002)

**화면명**: 챌린지 풀기 (공통 래퍼)

**사용자 목표**: 선택한 챌린지의 문제를 풀고 제출한다.

**진입 경로**:
- S-002 챌린지 카드 클릭
- S-001 챌린지 카드 직접 클릭
- URL 직접 입력 (`/challenges/:id`)

**영역 구성**:

| 영역 | 역할 | 포함 컴포넌트 |
|------|------|--------------|
| 챌린지 헤더 | 챌린지명, 타이머(경과 시간), 뒤로가기 | ChallengeHeader |
| 문제 설명 영역 | 챌린지 유형별 지문·규칙 텍스트 | ProblemStatement |
| 문제 입력 영역 | 유형별 인터랙티브 입력 컴포넌트 (아래 명세) | ProblemInput |
| 제출 영역 | "제출하기" 버튼, 입력 완료 여부 표시 | SubmitArea |

**챌린지 유형별 입력 컴포넌트**:

| 챌린지명 | 입력 방식 | 입력 컴포넌트 |
|----------|-----------|--------------|
| 배수 수열 | 10칸 가로 그리드, 각 칸에 0-9 단일 숫자 입력 | NumberGridInput (1문제 또는 2문제 순차 표시) |
| 11배수 스도쿠 | 9×9 그리드, 빈 셀 클릭 후 숫자 키패드로 1-9 입력 | SudokuGridInput |
| 너는 바보입니다 | 수식 이미지 표시 후 단일 숫자 답 입력 | SingleNumberInput |
| 아름다운 수열 | 32칸 연결 그래프 그리드, 각 칸에 1-32 숫자 드래그·직접 입력 | GraphGridInput |
| 아 치킨먹고싶다 | 10문항 리스트, 각 문항 답 텍스트박스 | MultiQuizInput |

**4가지 상태** (모두 필수):

#### 정상 상태
챌린지 헤더 타이머 작동. 문제 설명 및 입력 컴포넌트 정상 렌더. 제출 버튼은 필수 입력 칸 전부 채워진 경우에만 활성화.

#### 빈 상태 (Empty)
문제 시작 직후, 아직 입력값이 없는 상태. 모든 입력 칸 비어있음, 제출 버튼 비활성. 타이머는 페이지 진입 즉시 시작.

#### 에러 상태 (Error)
- 제출 API 실패: "제출에 실패했습니다. [다시 시도]" 토스트 + 버튼 재활성화 (입력값 유지)
- 문제 데이터 로드 실패: "문제를 불러오지 못했습니다. [다시 시도]" 전체 영역 에러 + 재시도 시 타이머 리셋
- 세션 만료(비회원): 제출 시도 시 "세션이 만료되었습니다. 로그인 후 점수를 저장하세요." 모달, "로그인"·"가입 없이 보기" 버튼

#### 로딩 상태 (Loading)
문제 데이터 로드 중: 문제 설명 영역에 스켈레톤, 입력 영역 비활성. 제출 중: 버튼에 스피너 + "제출 중..." 레이블, 입력 영역 비활성.

**인터랙션**:

| 트리거 | 동작 | 결과 상태 |
|--------|------|----------|
| 입력칸 값 변경 | 입력 유효성 검사, 제출 버튼 활성/비활성 갱신 | 동일 화면 |
| "제출하기" 클릭 (입력 완료) | 점수 계산 API 호출, 타이머 정지 | 성공→S-004 / 실패→에러 토스트 |
| 타이머 영역 표시 | 경과 시간 초 단위 카운트업 (백그라운드 탭 포함) | 동일 화면 |
| 뒤로가기 클릭 | "풀이를 포기하시겠습니까?" 확인 모달 | 확인→S-002 / 취소→동일 화면 |

### S-004 (→ REQ-002, REQ-003, REQ-005, REQ-007)

**화면명**: 챌린지 결과

**사용자 목표**: 점수와 정답 내역을 확인하고, 랭킹 등록 또는 IQ 응시권 결제로 전환한다.

**진입 경로**:
- S-003 제출 성공 후 자동 이동

**영역 구성**:

| 영역 | 역할 | 포함 컴포넌트 |
|------|------|--------------|
| 결과 요약 카드 | 획득 점수, 소요 시간, 정답 수/전체 문항 수 | ScoreCard |
| 랭킹 등록 안내 | 비회원: 가입 유도 / 회원: 즉시 등록 상태 표시 | RankingCTA |
| 정답 상세 (Should) | 문제별 정답·오답 표시, 점수 분해 내역 (REQ-007) | AnswerDetail |
| IQ 응시권 배너 | "내 IQ가 궁금하다면" 결제 유도 | ConversionBanner |
| 재도전·다른 챌린지 | "다시 도전" / "다른 챌린지 풀기" 버튼 | ActionButtons |

**4가지 상태** (모두 필수):

#### 정상 상태 (회원)
점수·시간·정답 내역 모두 표시. 랭킹 등록 완료 메시지. 내 순위 표시 ("현재 랭킹 N위"). IQ 응시권 배너 노출.

#### 빈 상태 (Empty)
비회원 제출 직후: 점수·시간은 세션 기반 임시 표시. "랭킹에 등록하려면 회원가입이 필요합니다" 안내. "카카오로 가입" / "이메일로 가입" / "가입 없이 계속" 선택지. "가입 없이 계속" 선택 시 배너만 노출, 랭킹 내 순위 영역 미표시.

#### 에러 상태 (Error)
- 점수 저장 API 실패 (회원): "점수 저장에 실패했습니다. [다시 시도]" 토스트. 재시도 버튼으로 저장 재요청. 점수 카드 자체는 로컬 계산값으로 표시.
- 랭킹 순위 조회 실패: 내 순위 영역에 "순위를 불러오지 못했습니다." 인라인 에러.

#### 로딩 상태 (Loading)
결과 페이지 진입 직후: 점수 카드 스켈레톤 표시. 랭킹 순위 조회 중: 내 순위 영역 스피너.

| "가입 없이 계속" 클릭 | 랭킹 미등록 상태로 결과 화면 유지 | S-004 빈 상태 |

| "다시 도전" 클릭 | S-003 재진입 (타이머 리셋) | S-003 빈 상태 |
