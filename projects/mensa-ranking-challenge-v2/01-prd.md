## 1. WHY — 왜 이걸 만드는가

멘사코리아는 IQ 상위 2%를 인증하는 국제 단체로, 국내 SNS 채널을 통해 IQ 챌린지 콘텐츠를 꾸준히 발행해 왔다. 팔로워 반응은 높지만 도전-기록-비교로 이어지는 사용자 경험이 부재하여 일회성 콘텐츠 소비에 머물렀다.

이 서비스는 기존 SNS 챌린지 콘텐츠를 웹 플랫폼으로 이식하여 "풀기 → 점수 확인 → 랭킹 경쟁 → IQ 테스트 응시 고려"의 전환 퍼널을 만든다. 비회원도 챌린지에 참여할 수 있게 하여 멘사에 관심 있는 일반인을 자연스럽게 유입시키고, 랭킹과 멘사 회원 배지를 활용한 사회적 동기를 부여한다.

핵심 비즈니스 목표는 IQ 테스트 응시권 결제 전환이다. 챌린지 자체는 무료로 운영하되, 참여자가 자신의 점수에 자극받아 정식 IQ 테스트 응시권을 구매하도록 유도하는 구조다.

## 2. 1차 사용자

**주 사용자**: 멘사코리아 SNS를 팔로우하거나 IQ 챌린지 콘텐츠를 접한 20~40대 직장인·대학생. 평소 퍼즐·두뇌 게임에 관심 있으며 자신의 IQ나 논리력을 가늠해 보고 싶어 한다.

**부 사용자**: 기존 멘사코리아 회원 — 챌린지 참여 후 멘사 회원 배지를 표시하여 커뮤니티 내 위상을 강화하려는 동기.

**사용자 맥락**: 점심시간·출퇴근 이동 중(웹 브라우저) 또는 주말 여가 시간에 "이거 나 풀 수 있나?" 하는 호기심으로 접근. 단번에 5문제를 완료하거나, 막히면 다음에 재시도하는 패턴.

## 3. 성공 지표 (측정 가능한 형태)

| 지표 | 목표값 | 측정 방법 |
|------|--------|----------|
| 챌린지 참여자 수 (누적) | 출시 3개월 내 500명 이상 | 회원가입 또는 게스트 제출 이벤트 수 |
| 챌린지 완료율 | 40% 이상 (5문제 전부 제출 기준) | 완료 이벤트 / 시작 이벤트 비율 |
| IQ 테스트 응시권 결제 전환율 | 5% 이상 (챌린지 참여자 대비) | 결제 완료 수 / 챌린지 참여자 수 |

## 4. 기능 범위 (MoSCoW)

### Must (5개 이하)

1. **REQ-001 챌린지 문제 풀기** — 5종 챌린지(배수 수열, 11배수 스도쿠, 너는 바보입니다, 아름다운 수열, 아 치킨먹고싶다) 각 문제를 웹에서 제출하고 정답 여부 즉시 확인
2. **REQ-002 점수 산정 및 저장** — 정답 여부 × 풀이 시간 가중치로 점수 계산. 회원은 점수 저장, 비회원은 세션 내 임시 저장
3. **REQ-003 랭킹 조회** — 챌린지별 랭킹 + 전체 통합 랭킹 조회 (상위 N명 표시)
4. **REQ-004 회원가입·로그인** — 이메일 가입 또는 소셜 로그인(카카오·구글). 멘사 회원은 별도 인증 후 배지 부여
5. **REQ-005 IQ 테스트 응시권 결제** — 카드·카카오페이로 응시권 구매 (PG사 연동)

### Should

- **REQ-006 멘사 회원 배지 표시** — 멘사 회원 인증 완료 시 프로필·랭킹에 배지 노출
- **REQ-007 챌린지 결과 상세 화면** — 문제별 정답·오답 확인 + 점수 분해 내역

### Could

- **REQ-008 월별 랭킹 초기화** — 매월 1일 랭킹 리셋 (초기화 여부는 운영 정책 결정 후)
- **REQ-009 챌린지 재도전** — 동일 챌린지 재시도 허용 (점수는 최고점 기록)

### Won't (제외 범위 명시)

- 모바일 앱 (v1.0은 웹 전용)
- 커뮤니티·댓글·소셜 공유 기능
- 힌트 유료화
- 멘사 회원 DB 완전 통합 (배지 표시 수준에서 종료)
- 챌린지 5종 외 추가 문항 (v2.0 이후)

## 5. 주요 사용자 시나리오

### 시나리오 1: 정상 경로 — 비회원 최초 참여 후 가입

1. 사용자가 SNS 링크를 타고 랭킹챌린지 메인 페이지에 진입한다
2. 로그인 없이 "챌린지 시작" 버튼을 누른다
3. 배수 수열 챌린지를 선택하여 문제를 풀고 제출한다
4. 정답 여부와 소요 시간 기반 점수를 확인한다
5. "랭킹에 등록하려면 회원가입이 필요합니다" 안내를 보고 카카오 소셜 가입을 완료한다
6. 전체 랭킹에서 자신의 순위를 확인하고, IQ 테스트 응시권 배너를 클릭한다

### 시나리오 2: 실패/예외 경로 — 비회원이 점수 저장 없이 이탈

1. 사용자가 게스트 상태로 챌린지를 완료한다
2. "가입 없이 계속하기"를 선택하여 결과 화면에서 이탈한다
3. 브라우저를 닫거나 페이지를 새로고침하면 세션이 만료되어 점수가 사라진다
4. 재방문 시 동일 챌린지를 처음부터 다시 시작해야 함을 안내한다

### 시나리오 3: 실패/예외 경로 — 결제 실패

1. 사용자가 IQ 테스트 응시권 구매를 시도한다
2. 카드 한도 초과로 결제가 실패한다
3. 시스템이 "결제 실패" 메시지와 함께 다른 결제 수단(카카오페이)을 안내한다
4. 사용자가 카카오페이로 재시도하여 결제를 완료한다
