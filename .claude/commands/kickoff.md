# /kickoff — 신규 프로젝트 착수

신규 프로젝트 1건을 **PRD → 기술 검토 → UX 명세 → 노션 등록**까지 자동 순차 진행한다.

## 인자
- `$1` 고객사명 (필수)
- `$2` 프로젝트명 (필수)
- `$3` PM (선택, 미지정 시 사용자에게 질의)

## 절차 (팀장 Claude가 수행)

### 1단계 — 슬러그·STATE 초기화

1. 고객사·프로젝트명으로 **슬러그 생성** (영문 소문자 + 하이픈, CLAUDE.md §4)
   - 예: "BNSYSTEM / Verihum 사람 인증" → `verihum-auth`
   - 슬러그 충돌 시 접미사 `-v2` 등으로 구분
2. `projects/<slug>/` 디렉토리 생성
3. `projects/<slug>/STATE.md` 초기화 (CLAUDE.md §4 필수 필드 모두 포함)
   - 고객사, 슬러그, Notion Page ID(미등록), PM, 현재 단계(기획), 마지막 업데이트(오늘)
   - 산출물 인덱스 3개 빈 체크박스
   - Decision Log: "`/kickoff`로 착수 (YYYY-MM-DD)"
4. `projects/_INDEX.md`에 신규 행 추가 또는 `weekly-status` Skill 호출로 재생성

### 2단계 — 서비스기획자 호출

- Agent: `서비스기획자`
- 입력: 슬러그, 고객사, 프로젝트명, PM, 비즈니스 배경(사용자에게 질의)
- 완료 후 **PRD 자가 점검 통과율 ≥ 5/7 확인**
  - 미달 → 중단, 사용자에게 "재작성 또는 요구사항 재검토" 옵션 제시 (CLAUDE.md §9)

### 3단계 — 기술검토자 호출

- **전제**: `01-prd.md` 존재 + 자가 점검 ≥ 5/7
- Agent: `기술검토자`
- 완료 후 **기술 검토 자가 점검 ≥ 4/5 확인**

### 4단계 — UX기획자 호출

- **전제**: `01-prd.md` + `02-tech-review.md` 둘 다 존재 + 각 자가 점검 통과
- Agent: `UX기획자`
- 완료 후 **UX 자가 점검 ≥ 3/4 확인** (빈·에러·로딩 누락 시 자동 재작성)

### 5단계 — 노션관리자 호출

- Agent: `노션관리자`
- 작업: 3개 산출물을 노션에 새 프로젝트 페이지로 등록
  - `API-post-page`로 PROJECT DB 하위에 신규 페이지 생성 (`ask` 권한 → 사용자 승인)
  - `API-patch-block-children`으로 각 산출물 블록 추가
- STATE.md의 `Notion Page ID` 필드 업데이트

### 6단계 — 사용자에게 최종 보고

CLAUDE.md §10 표준 출력 포맷 준수:

```
[팀장] 신규 프로젝트 착수 완료
- 슬러그: <slug>
- 산출물: projects/<slug>/{01-prd.md, 02-tech-review.md, 03-ux-spec.md}
- 노션: <page URL>
- 자가 점검 요약: PRD N/7, Tech N/5, UX N/4
- 오픈 이슈: N건
```

## 게이트 로직 (Stage 5 에이전트 호출 원칙)

각 단계 사이에 다음을 강제한다:

| 게이트 | 조건 | 미달 시 |
|--------|------|--------|
| 2→3 | PRD 자가 점검 ≥ 5/7 | 서비스기획자 재작성 요청 또는 중단 |
| 3→4 | 기술 검토 자가 점검 ≥ 4/5 | 기술검토자 재작성 요청 |
| 4→5 | UX 자가 점검 ≥ 3/4 + 빈·에러·로딩 없음 | UX기획자 재작성 요청 |
| 5 | 노션관리자 자가 점검 ≥ 6/7 | 롤백 후 재시도 1회 |

## 중단 조건

- 사용자가 중단 요청
- 자가 점검 3회 연속 미달 (CLAUDE.md §9 재시도 한계)
- 노션 API 오류 2회 이상
- 고객사·프로젝트명이 비어있거나 불명확

## 주의
- **사용자 질의는 가능한 한 한 번에 묶어서** (`AskUserQuestion`)
- 중간 산출물을 사용자에게 모두 보여주지 말고 **요약+링크**만 (CLAUDE.md §10)
- 각 에이전트의 개별 완료 보고는 팀장이 내부적으로 수집하고, 사용자에게는 최종 6단계 보고만 전달
