# /status — 활성 프로젝트 현황 조회

`projects/_INDEX.md`를 갱신하고 주간 요약을 사용자에게 출력한다.

## 인자
- 인자 없음 → 전체 활성 프로젝트 요약 + `_INDEX.md` 재생성
- `$1` 프로젝트명 또는 슬러그 (선택) → 해당 프로젝트 1건만 상세 출력 (`_INDEX.md` 갱신 없음)

## 절차 (팀장 Claude가 수행)

### 인자 없을 때 (전체 현황)

1. **`weekly-status` Skill 호출**
2. Skill이 수행:
   - `Glob`으로 `projects/*/STATE.md` 전수 매칭
   - 각 STATE.md 파싱 (프로젝트명, PM, 현재 단계, 마지막 업데이트, 산출물 인덱스)
   - 각 산출물의 `## 자가 점검` 섹션에서 통과율 추출
   - `report-template.md` 기반으로 `_INDEX.md` 재생성
3. 사용자에게 **주간 요약 3~5줄** 출력:
   - 활성 N건 / 종료 M건(제외)
   - 자가 점검 미달 K건
   - 7일 미갱신 L건

### 인자가 있을 때 (1건 상세)

1. 슬러그 매칭 → `projects/<slug>/STATE.md` 읽기
2. 존재하는 산출물 각 자가 점검 통과율 추출
3. 사용자에게 표 형식으로 출력:
   ```
   [프로젝트명] 상세 현황
   - 슬러그: <slug>
   - PM: <name>
   - 현재 단계: <단계 — 4단계: 기획중 / MVP-구현중 / MVP-완료 / 종료>
   - 마지막 업데이트: <date>
   - 산출물 (4종):
     - 01-prd.md: N/7 ✓/✗
     - 02-tech-review.md: N/5 ✓/✗
     - 03-ux-spec.md: N/4 ✓/✗
     - 04-prototype-mvp/: N/7 ✓/✗ (P-NNN N건, NA N건)
   - 오픈 이슈: N건
   - 다음 액션: <STATE.md의 다음 액션 섹션>
   ```

## 게이트 로직
- 활성 프로젝트 0건 → `_INDEX.md`에 "아직 등록된 신규 프로젝트 없음" 템플릿 유지
- 인자 슬러그가 존재하지 않음 → "프로젝트를 찾을 수 없습니다. 사용 가능한 슬러그: <목록>" 응답

## 주의
- **기존 노션 진행 프로젝트는 대상 아님** — 하네스는 `projects/` 하위만 관리
- `_INDEX.md`는 **항상 재생성** (덮어쓰기 허용 — 이 파일은 인덱스이므로 원본 아님)
- STATE.md 자체는 절대 수정하지 않음 (읽기 전용)
