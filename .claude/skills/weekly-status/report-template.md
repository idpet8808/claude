# _INDEX.md 재생성 템플릿

## 파일 머리 (고정)

```markdown
# 활성 프로젝트 인덱스

> {{YYYY-MM-DD}} 기준. 하네스에서 관리 중인 **신규 프로젝트**의 상태판이다.
> 기존 노션 진행 프로젝트는 하네스 대상이 아니며, **신규 영업·신규 기획 건만** `/kickoff`로 등록한다.
```

## 활성 프로젝트 표 (동적 생성)

### 활성 프로젝트가 1개 이상일 때

```markdown
## 활성 프로젝트 ({{N}}건)

| 슬러그 | 프로젝트 | PM | 현재 단계 | 자가점검 | 오픈이슈 | 마지막 갱신 | STATE |
|--------|----------|-----|----------|---------|---------|-----------|-------|
| `{{slug}}` | {{프로젝트명}} | {{PM}} | {{단계}} | PRD {{n}}/7, Tech {{n}}/5, UX {{n}}/4 | {{n}}건 | {{YYYY-MM-DD}} | [열기]({{slug}}/STATE.md) |
```

**행 정렬 규칙**: 마지막 갱신 날짜 역순 (최근 작업이 위)

### 활성 프로젝트가 0개일 때 (빈 상태)

```markdown
## 활성 프로젝트

_아직 등록된 신규 프로젝트 없음. `/kickoff <고객사> <프로젝트명> [PM]` 명령으로 착수._
```

## 경고 섹션 (조건부 삽입)

### 자가 점검 미달 프로젝트가 있을 때

```markdown
## ⚠ 주의: 자가 점검 미달 프로젝트

아래 프로젝트는 산출물의 자가 점검 통과율이 85% 미만입니다. 후행 에이전트 호출이 차단됩니다.

- `{{slug}}` — {{산출물명}} {{n}}/{{N}} → 재작성 필요
```

### 7일 이상 미갱신 프로젝트가 있을 때

```markdown
## ⚠ 주의: 7일 이상 미갱신 프로젝트

- `{{slug}}` — 마지막 갱신 {{YYYY-MM-DD}} ({{N}}일 전)
```

## 파일 말미 (고정)

```markdown
---

## 운영 원칙

- **신규 건만 등록**: 기존 노션에서 진행 중인 프로젝트는 하네스 대상 아님 (노션관리자가 MCP로 직접 조회)
- **슬러그 규칙**: 영문 소문자 + 하이픈
- **진입점**: `/kickoff <고객사> <프로젝트명> [PM]`
- **현황 조회**: `/status`
- **노션 동기화**: `/sync-notion <파일경로>`
```

## 사용자 응답 포맷 (_INDEX.md 갱신 후 출력)

```
[팀장] 주간 현황 갱신 완료
- _INDEX.md: projects/_INDEX.md
- 활성 {{N}}건 / 종료 {{M}}건 (제외)
- 자가 점검 미달: {{K}}건
- 7일 미갱신: {{L}}건
```

**출력 규칙**: CLAUDE.md §10 준수 — 3~5줄, 에이전트별 개별 리포트 생략, 장황한 설명 금지.
