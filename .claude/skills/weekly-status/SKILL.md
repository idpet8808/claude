# weekly-status — 주간 현황 요약 Skill

## 언제 쓰나
- `/status` Slash command 실행 시 팀장 Claude가 호출
- 사용자가 "현재 활성 프로젝트 어떻게 돼?"라고 물을 때
- 주간 보고서가 필요한 시점

## 호출 절차

1. **projects/ 하위 슬러그 디렉토리 전수 스캔**
   - `Glob` 도구로 `projects/*/STATE.md` 매칭
   - 발견된 STATE.md 파일 경로 배열 확보

2. **각 STATE.md 파싱** (first read)
   - 추출 필드:
     - 프로젝트명 (H1 제목)
     - 고객사
     - 슬러그
     - PM
     - 현재 단계
     - 마지막 업데이트
     - 산출물 인덱스 체크 상태 (01-prd.md, 02-tech-review.md, 03-ux-spec.md)
     - 오픈 이슈 개수
   - **"종료" 단계 프로젝트는 _INDEX.md에서 제외** (활성만)

3. **각 산출물의 자가 점검 통과율 추출** (선택)
   - `01-prd.md` 하단 `## 자가 점검` 섹션 파싱 → "통과율: N/7" 추출
   - `02-tech-review.md`의 N/5
   - `03-ux-spec.md`의 N/4

4. **report-template.md 로드 → _INDEX.md 재생성**
   - 헤더: "활성 프로젝트 인덱스" + 업데이트 일자
   - 표: 슬러그 / 프로젝트 / PM / 현재 단계 / 자가점검 / 오픈 이슈 / STATE 링크
   - 하단: 운영 원칙 (유지)

5. **주간 요약 본문 출력** (사용자에게)
   - 총 활성 프로젝트 수
   - 진행 중 단계 분포
   - 자가 점검 미달(< 85%) 프로젝트 경고
   - 마지막 업데이트 7일 초과 프로젝트 경고

## 출력
- `projects/_INDEX.md` 갱신 (쓰기)
- 사용자 응답: 주간 요약 3~5줄 + _INDEX.md 경로

## 완료 보고 형식
```
[팀장] 주간 현황 갱신
- _INDEX.md: 활성 N건 갱신 (종료 M건 제외)
- 자가 점검 미달: K건 ({{슬러그 나열}})
- 7일 미갱신: L건 ({{슬러그 나열}})
```

## 주의
- 활성 프로젝트 0건이면 "아직 등록된 신규 프로젝트 없음" 템플릿으로 _INDEX.md 초기화
- 기존 노션 진행 프로젝트는 대상 아님 (하네스 외부)
- STATE.md 파싱 실패 시 해당 슬러그는 표에 `⚠ 파싱 실패` 행으로 표시 + 팀장 알림
